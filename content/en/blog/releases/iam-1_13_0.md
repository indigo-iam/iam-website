The IAM development team is pleased to announce the release of INDIGO IAM v1.13.0.

The main feature of this release is the support for OpenID Federation, a new OIDC specification to federate
OpenID Connect Providers (see [specification](https://openid.net/specs/openid-federation-1_0.html)),introduced as an experimental functionality.

This release also provides bug fixes and enhancements, as can be seen in the [release notes][release-notes].

The major highlights include:
* add user affiliation information into the home dashboard and tokens
* allow SCIM bulk operations
* allow to automatically provision accounts based on trusted external OIDC Providers
* support for custom JWT expiration during an access token request.

As usual, the IAM docker image can be obtained from [DockerHub][iam-login-service-docker].
