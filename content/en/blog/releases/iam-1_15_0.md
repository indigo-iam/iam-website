The IAM development team is pleased to announce the release of INDIGO IAM v1.15.0.

The main features and improvements in this release are:

* support for OIDF explicit client registration with the OpenID Connect Relying Party (RP) role
* support for SCIM 2.0 discovery endpoints, and addition of AARC User and Group schema extensions
* OPA-backed scope authorization with client-aware policies
* support for certificate-bound access tokens
* improved security through SHA-256 hashing of client secrets and configurable login lockout
* support for OIDC post-logout redirect URIs
* optimized access-token storage by persisting claims instead of complete JWT values

This release also includes some changes that may require configuration updates, including the removal of the `client_secret_jwt` authentication method and changes to WLCG group scope handling.

**Please note**: this release includes database schema and data migrations. Make sure to back up your database and review the upgrade instructions before upgrading.

More information in the [release notes][release-notes].

As usual, the IAM docker image can be obtained from [DockerHub][iam-login-service-docker].
