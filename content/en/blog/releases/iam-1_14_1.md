The IAM development team is pleased to announce the release of INDIGO IAM v1.14.1.

The main fixes in this release are:

* stricter redirect URI validation
* sanitization of the registration key in the error page
* sanitization of the *PasswordReplacedEvent* log message
* improved handling of the client secret when updating the client authentication method
* enforcement of client authentication method validation at the token endpoint

More information in the [release notes][release-notes].

As usual, the IAM docker image can be obtained from [DockerHub][iam-login-service-docker].
